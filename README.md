# Arlex Scents

Marketing and store-discovery site for **Arlex Scents** — long-lasting, affordable
oil-based inspired fragrances, Lemontree Mall, Alberton.

- Single self-contained `index.html` (inline CSS + vanilla JS, no build step).
- WhatsApp-first: no cart, checkout, payment or order flow. All prices are
  "price on request"; every conversion routes to WhatsApp (073 433 8607),
  Facebook, or the physical store.
